      Do the winners keep winning?

      Each index ranked by growth in one period, then again in the next period of the same length.

      Hardly. Across 125 indexes, how well something did in one 15-year stretch says almost nothing about the next one. That's why chasing last decade's best sector is risky, and why a broad market index is a hard benchmark to beat.

      How it works

      1. Data: Python downloads monthly, value-weighted returns from the Kenneth R. French Data Library, the standard source for academic research on US stocks, and parses the first table of each file.
      2. Analysis: pandas computes each index's compound annual growth, annualized volatility, Sharpe ratio against the risk-free rate, worst peak-to-trough drop, and growth of $1, for any window. Indexes missing any month in a window are left out of it.
      3. Ranking: indexes are sorted by the chosen measure. Ranks from back-to-back windows are compared with a Spearman correlation.
      4. This page: python -m indexer export writes the results to one JSON file. The page only displays it; all the math is in the tested Python package.

      Options: --years, --by cagr|sharpe|max_drawdown|volatility|growth, --group Industry, --end 2008-12. 15 pytest tests cover parsing, every measure, ranking, and the exported results.

      Data: Kenneth R. French Data Library (Tuck School of Business, Dartmouth), built from CRSP. Returns include dividends and are before fees and taxes; indexes are research portfolios, not funds you can buy directly. For learning, not investment advice.
